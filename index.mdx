## One account, two interfaces

The REST API is available at `https://reporters.io/api/v1`. The MCP server is available at `https://reporters.io/api/mcp`. Both use your Reporters.io API key and account access.

Search and profile responses keep contact details separate. Use a dedicated [contact reveal operation](/contacts) when your account and API key can access them.

## What you can build

- Find journalists who cover a topic and inspect their profile.
- Read article references associated with a reporter or outlet.
- Research an outlet and the reporters associated with it.
- Reveal available contact details with explicit contact access.

Start with the [quickstart](/quickstart), then read [authentication](/authentication) and [data handling](/data-policy).
