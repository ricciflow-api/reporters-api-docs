The Reporters.io agent skill guides an assistant through media research using the REST API. An active Professional (Pro) subscription is required to create an API key and use REST or MCP. It pairs task instructions with a small client so the agent can search, inspect records, and cite article references.

## Get the skill

Use the public [reporters-agent-skills repository](https://github.com/ricciflow-api/reporters-agent-skills). Install it with the following command, or follow the repository README to copy it into your agent's supported skill directory:

```bash
npx skills add ricciflow-api/reporters-agent-skills --skill reporter-research
```

The installer requires Node.js 22.20 or later. Choose Claude Code, Cursor, Codex, or another supported agent when prompted. To target one agent, append `-a claude-code`, `-a cursor`, or `-a codex`. See the [installer reference](https://github.com/vercel-labs/skills/blob/main/docs/commands.md).

For a manual installation, use the [reporter-research directory](https://github.com/ricciflow-api/reporters-agent-skills/tree/main/skills/reporter-research) or copy `skills/reporter-research` into your client's supported skills directory. Invoke `$reporter-research` in clients that support named skill invocation. Configure `REPORTERS_API_KEY` in the agent's protected environment, or connect the [hosted MCP server](/mcp-guide).

The skill uses the API at `https://reporters.io/api/v1`. Create a key by entering a name; all six API permissions are included automatically, with no automatic expiration. The account must retain active Pro access. Revoked keys and keys on accounts without active Pro access do not authorize requests; stop when access is denied. See [authentication](/authentication) for key management.

## Run a research task

Give the agent the topic, geography, or outlet you want to investigate and the evidence you need. For example:

> Research journalists who cover climate technology. Use their profile and article references to explain why each person belongs on the shortlist. Keep contact reveal separate until I select a reporter.

Review the returned evidence before using it in an outreach workflow. The skill does not send messages.

## Choose between MCP and skills

Use [MCP](/mcp-guide) when your assistant supports tool connections. Use the skill when your agent runs local scripts and can load task instructions. Both paths use the same account, included API permissions, and data-access rules.
